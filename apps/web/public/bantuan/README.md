# Tangkapan layar untuk halaman bantuan

Taruh tiga berkas PNG di folder ini dengan nama persis seperti berikut, lalu halaman
`/bantuan` otomatis memakainya menggantikan ilustrasi sketsa. Tidak perlu mengubah kode.

| Berkas              | Isi yang diharapkan                                                      | Dipakai di langkah |
| ------------------- | ------------------------------------------------------------------------ | ------------------ |
| `nomor-pesanan.png` | Detail Pesanan Shopee, dengan nomor pesanan terlihat di bagian atas      | 1                  |
| `username.png`      | Menu Saya, dengan username terlihat di bawah nama                        | 2                  |
| `nomor-hp.png`      | Alamat Pengiriman pada detail pesanan, dengan empat digit terakhir nomor | 3                  |

Panduan singkat:

- potong hanya bagian yang relevan, jangan seluruh layar HP;
- sembunyikan nama, alamat, dan nomor pesanan asli sebelum diunggah, kecuali contoh palsu;
- lebar maksimal 320 px ditampilkan, jadi berkas 640 px sudah cukup tajam di layar ponsel;
- jangan memakai tangkapan layar dari akun pembeli sungguhan tanpa izin.

Kalau berkas tidak ada, halaman menampilkan ilustrasi sketsa berlabel "Ilustrasi layar, bukan
tangkapan layar". Itu disengaja: sketsa yang jujur lebih baik daripada tangkapan layar palsu.
